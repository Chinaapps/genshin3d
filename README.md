# 提瓦特 · 3D 探索框架

原神风格 HUD 的 Three.js 3D 探索 / 战斗框架（去掉了顶部那一排图标，保留下方全部功能）。

## 文件结构

```
genshin3d/
├── index.html              入口页面（HUD 布局）
├── style.css               全部界面样式（米色 + 金色描边）
├── script.js               3D 场景、角色、战斗、输入、主循环
├── README.md
└── resources/
    └── vendor/
        └── three.min.js    Three.js（UMD，本地加载，离线可跑）
```

## 运行

仓库已开启 GitHub Pages，直接访问 `https://chinaapps.github.io/genshin3d/`。
本地运行：用浏览器打开 `index.html` 即可（相对路径引用，无需服务器）。

## 下方功能（全部可用）

- 左侧队伍列表：点击图标或按 `1`–`4` 切换角色，独特元素配色与血条
- 左下虚拟摇杆：拖动移动（也支持 WASD）
- 右下动作键：普攻（带体力环）、元素战技 E（CD 环）、元素爆发 Q（能量环）、冲刺 Shift、跳跃 空格
- 伤害飘字、受击红闪、元素粒子与冲击波特效
- 拖动画面转视角、滚轮缩放

## 视觉

- 低多边形草原场景、天空渐变、雾效、软阴影
- 米色羊皮纸风格 HUD 与金色装饰线
- 角色模型由基础几何体拼装，按元素换色
